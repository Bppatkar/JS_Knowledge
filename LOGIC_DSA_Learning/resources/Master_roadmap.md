Focus on the small number of reusable:

- Data Structures
- Algorithms
- Patterns
- Techniques

> "Which 20% of algorithms and patterns give me the most leverage on unknown problems?"

# 🎯 CONSTRAINT-FIRST RULE

Before selecting a pattern:

```text
1. What is the input?
2. What is n?
3. What are the value constraints?
4. What operations are required?
5. What brute force would cost?
6. What TC is affordable?
7. What SC is affordable?
8. Which Data Structure supports the needed operations?
9. Which Algorithm gives the required performance?
10. Which Pattern emerges?
```

Never choose a pattern merely because the problem "looks like" one.
