# Recognition Rules

Use Traversal Pattern when:

- Every element ko dekhna hai.
- Search karna hai.
- Count karna hai.
- Sum nikalna hai.
- Print karna hai.
- Validation karni hai.

Recognition Keywords:

- For every element
- Iterate
- Visit each element
- Scan array

---

# Engineering Thinking

Array ek contiguous memory block hota hai.

Har element fixed index par stored hota hai.

Traversal ka matlab:

Move from left to right while processing every element exactly once.

Engineer pehle sochta hai:

Input

↓

Output

↓

State

↓

Traversal

Code baad mein aata hai.

---

# Common Mistakes

❌ Loop boundary galat likhna

❌ Index aur value ko confuse karna

❌ Direct code likhna without dry run

❌ State update ko ignore karna
