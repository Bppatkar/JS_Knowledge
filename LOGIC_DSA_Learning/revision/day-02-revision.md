# Recognition Rules

## State Update

Use when:

Current value change ho rahi ho.

Examples:

- Running Sum
- Running Count
- Toggle
- Current Maximum

---

## Build New Array

Use when:

Question explicitly new array return karne ko bole.

Recognition:

- Return new array
- Transform array
- Mapping

---

## Comparison Pattern

Use when:

Har element compare karna ho.

Examples:

- Largest
- Smallest
- Equal
- Greater than
- Less than

---

## Early Exit

Use when:

Answer milte hi loop stop ho sakta ho.

Recognition:

- Exists?
- Contains?
- First Match
