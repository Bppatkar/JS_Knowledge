# Recognition Rules

## Linear Search

Use when:

- Find an element.
- Check whether element exists.
- Find first occurrence.

Recognition Keywords:

- Find
- Search
- Exists
- Contains

Time Complexity

O(n)

---

## Count Pattern

Use when:

Need to count occurrences based on a condition.

Examples

- Even numbers
- Odd numbers
- Positive numbers
- Negative numbers
- Zeroes
- Characters

Recognition

Question contains:

"How many..."

---

## Running Count Pattern

Use when:

Need continuous counting while traversing.

Examples

- Consecutive Ones
- Consecutive Characters
- Consecutive Days

Recognition

Current streak matters.

---

❌ Forgetting counter initialization

# Interview Notes

Difference between Count and Running Count

Total occurrences.

Running Count

Continuous occurrences.
