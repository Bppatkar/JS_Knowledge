# Recognition Rules

Recognition

- Largest
- Highest
- Maximum
- Greatest
- Richest

State

Current

↓

## Minimum Pattern

Recognition

- Smallest

- Minimum
- Cheapest

## Best Index Tracking

Use when:

Question asks for position instead of value.

Examples

- Index of Maximum
- Index of Minimum
- First Maximum

---

## First Occurrence

Recognition

Return immediately or save first index.

## Last Occurrence

# Engineering Thinking

Engineer tracks two states.

Current State

Best State

Every iteration compares:

Is Current better than Best?

If Yes

↓

Update Best

Sometimes update Index too.

---

# Common Mistakes

❌ Updating value but not index

❌ Wrong initialization

❌ Using >= instead of >

❌ Forgetting first occurrence condition

# Interview Notes
