v9

Added Problem Decomposition First Principle.

The learning methodology was expanded so that complex DSA problems are taught by decomposing them into smaller requirements and required pieces of information.

Added:

- Requirement → Information → Technique → Combination reasoning.
- Component-by-component problem analysis.
- Explicit explanation of why each data structure / state / operation provides the required information.
- Pattern composition reasoning.
- Constraint-driven algorithm selection.
- Concept evolution through controlled problem ladders.
- Approximate 15–20 problem target for major patterns.
- Progressive difficulty with small conceptual modifications between problems.
- Explicit distinction between previously understood concepts and newly introduced concepts.
- Lightweight concept-first revision.
- Revision compression using the 80/20 principle.
- Pattern-blind revision with modified requirements and constraints.
- Constraint variation in CCRS to train algorithm selection.
- Concept retention prioritized over question memorization.
